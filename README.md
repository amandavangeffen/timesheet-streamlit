# 📊 Análise Timesheet — Dashboard Streamlit

Este repositório contém a aplicação em **Streamlit** integrada ao **Snowflake (Snowpark)** para monitoramento e análise de lançamentos de horas (timesheet), aderência e entregas no prazo por unidade e área.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.10+**
* **Streamlit** (Interface gráfica interativa)
* **Snowflake / Snowpark** (Processamento de dados em nuvem)
* **Pandas / NumPy** (Manipulação e agregação de dados)
